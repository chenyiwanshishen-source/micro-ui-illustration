# 案例观察

以下是历史试画中出现的问题及可用的修订思路，不是所有作品的判定规则。

| 现象 | 可以尝试的调整 |
|---|---|
| 卡片加色块像空壳，工具感较弱 | 研究对象的识别特征与功能结构，调整尺度对比 |
| 时间标签盖住末尾日期 | 移动附件或重排其锚点，再观察整组关系 |
| 英文标签一侧偏挤 | 按字体测量内容，调整容器、图标槽和留白 |
| 列表行距漂移 | 从共享行盒生成位置，再作光学校正 |
| 原本想表达浮层，却画成左右分栏 | 重新研究前后层关系，让后景与前景各自成立 |
| 代码检查正常但画面粗糙 | 回到参考对比轮廓、尺度、细节密度和光影 |

对同一问题可能有多种解法，选择最符合当前构图与风格的方式。
