# 用户参考图片存储目录 (Reference Images)

本目录用于存放用户提供并在对话中确认学习的参考图稿。

## 目录规则

1. **按需存储**：用户发送参考图片并说明想借鉴的特点时，图片将保存至此目录（如 `01-custom-dashboard.png`）。
2. **分析与索引**：每存入一张新图，AI 将在 `references/visual-reference-map.md` 中记录其造型、色彩、层次、构图、光影分析，并明确标注“可借鉴特征”与“禁止机械照搬的内容”。
3. **版权纯净**：开源版本默认不预置未授权的第三方外部商业图稿；无参考图时，AI 直接采用系统内置的 Micro-UI 设计规范与 `assets/examples/` 原创案例进行绘制。
