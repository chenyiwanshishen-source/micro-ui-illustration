# 色彩角色与映射

先判断颜色在参考中的面积、对比和功能，再建立角色到目标项目令牌的集中映射。不把参考图片的具体色值当成通用配色。

| 源码角色 | 用途 | 项目映射依据 |
|---|---|---|
| `--illus-base` | 画布 | canvas |
| `--illus-carrier` | 白色实体表面 | surface |
| `--illus-primary` | 主体焦点 | 用户选定色族的强调色令牌 |
| `--illus-primary-tint` | 伴生浅色 | 同色族浅底令牌 |
| `--illus-secondary` | 辅助焦点 | 另一色族或中性色，按画面需要选择 |
| `--illus-text` | 必要文字与符号 | text.primary |
| `--illus-text-secondary` | 次要信息 | text.secondary |
| `--illus-neutral-1` | 弱结构色面 | 项目浅中性色令牌 |
| `--illus-shadow` | 阴影 | 项目阴影色或中性深色令牌 |

已有案例可能使用 accent、border、placeholder 等附加角色，按其实际用途映射；角色名不是允许随意添加颜色的理由。不强制每次用满角色，也不强制增加辅助色。

项目现有 Token 是唯一颜色来源。没有设计系统时，建立单独的角色配置，绘制源码只引用配置。源码不内联十六进制、rgb/rgba/hsl 颜色字面量；阴影通过颜色角色加 opacity 表达。

独立 SVG 为兼容外部查看器，可以在导出阶段解析变量并写入最终颜色值；同时交付角色映射源。导出后的颜色字面量不是新增配色。修改主色时，伴生浅色、阴影与文字对比应一起检查。
