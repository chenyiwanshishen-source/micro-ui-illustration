# 把参考转成画法

参考选择与造型判断统一见 [主入口](../SKILL.md#从参考到造型与构图)。本文只帮助把已选定的具体效果转成实现；按需要查对应 SVG 的分组、路径、坐标或滤镜，再回看渲染结果。

## 观察什么，如何转成实现

按当前要解决的问题选择下列角度，无需逐项检查：

| 图片中观察的内容 | 对照SVG寻找的实现 | 在新图中怎样使用 |
|---|---|---|
| 主体占画板多少，哪一侧留白更多 | 主体包围框、位置与变换中心 | 根据新主体的轮廓调整尺度与位置 |
| 曲线在哪里转弯，连接处是否顺滑 | 节点位置、控制柄方向与长度 | 用相同的曲线构造方式绘制新轮廓 |
| 两个物体怎样遮挡，哪些边仍然可见 | 绘制顺序、完整底层形状、裁切范围 | 根据新物体的前后关系安排分组与遮挡 |
| 标签左右空隙、图标到文字的距离 | 文字实际宽度、容器边界、内部间距 | 用本次文字重新计算容器尺寸与位置 |
| 哪些细节让它像真实控件或物件 | 内容区域、对齐轴、重复部件与功能结构 | 迁移结构的组织方式，按新对象重建内容 |
| 接触处与远离物体处的阴影有何差别 | 阴影的形状、偏移、模糊、透明度及滤镜区域 | 根据新物体离底面的距离与光向调整投影 |
| 表面为什么有厚度或材质感 | 侧面路径、渐变方向、描边、局部纹理 | 为需要表现的表面选择相应构造方法 |

例如，观察到标签文字右侧比左侧挤，就对照文字边界和容器边界，分别计算两侧空隙；迁移到新标签时按新文字宽度排布，而不是照搬旧标签宽度。观察到近处阴影集中、远处阴影扩散，就查找是否由不同阴影层或不同形状形成，再按新图的空间关系调整。

重复结构适合写成参数化部件，例如行、标签、路径、投影或纹理生成器。[layout.py](../scripts/layout.py) 是其中一种可选辅助；已有工具或直接绘制同样可以使用。

[简洁案例数据](../styles/micro-ui/simple-construction.json)记录三张历史图稿的实际构造，可用于理解比例与分组。[Typography模板](../templates/typography/TEMPLATE.md)提供更丰富的工具场景；两组资源体现不同密度，选用时可考虑当前目标。

需要并排检查时，可用 [review_sheet.py](../scripts/review_sheet.py) 将已渲染 PNG 排成对照图（需要 Pillow）；视觉复检要求见主入口。

绘制时可综合参考分析、参数化构造和对照修订的思路，绘制方法按当前主题自由发展。
