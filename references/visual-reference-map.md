# 参考图谱：提取与舍弃

绘制前实际打开参考；不能仅凭文件名判断。先指出本次迁移的特征，再决定构图。以下不是每张图都要加入的元素清单。

| 素材 | 提取的造型知识 | 不默认照搬 |
|---|---|---|
| 01-typography-and-3d-tokens.png | 大字标与小工具条的尺度反差、错层悬浮、局部斜纹、分层柔影 | 业务文字、所有控件同时出现、每张都加仪轨 |
| 02-foundations-index-cards.png | Aa 与基准标尺、圆角尺寸示意、栅格节奏 | 页面卡片网格和说明文案；可借结构，再按本次空间方向处理 |
| 03-components-micro-ui.png | 独立真实控件、单焦点色、滑块与开关的功能轮廓、交互暗示 | 变体数量文字、每张都加光标 |
| 04-dashboard-stat-card.png | 大指标主次、低对比结构块、图标与数值的比例 | 具体数值和字段、无意义占位横条 |
| 05-workflow-connection-card.png | 两个对象的关系、格式标签、连接节点与前后尺度 | 营销文字、默认箭头或光晕 |
| 06-components-grid-system.png | 日历选中态、上传格式标签、开关球体、双色滑轨等身份特征 | 底部统计文字、整套控件网格 |
| 07-dataviz-and-code-cards.png | 图表的完整大色面、漏斗与流向轮廓、代码符号的身份 | 密集刻度、复杂坐标网格、小型伪代码横条 |
| 08-layered-folder-and-documents.png | 开口、纸张与前挡板的遮挡顺序、层叠厚度 | 固定颜色、文件夹作为所有主题的收纳隐喻 |

| [09-ui-color-accents.png](../assets/reference-images/09-ui-color-accents.png) | 浅色填充与同色较实描边、白灰退后、小面积跳色焦点 | 黄色标签、彩虹徽章、具体品牌与文字 |
| [10-green-blue-document-scenes.png](../assets/reference-images/10-green-blue-document-scenes.png) | 浅色承载、鲜色功能控件、深色前景重心；线纹露白减轻颜色重量 | 固定蓝绿组合、下载动作、每张都加光标或斜纹 |
| [11-green-blue-drafting-tools.png](../assets/reference-images/11-green-blue-drafting-tools.png) | 不同对象的颜色角色、深浅反差与遮挡、纹理和实体之间的颜色呼应 | 圆规尺子场景、具体色值、机械套用远浅近深 |

每次从主体轮廓、功能结构、大小关系、色彩面积、空间层级、细节密度中提取与任务有关的观察。将风格依据与场景构图区分开；喜欢一张参考，不等于照搬它的对象或版式。

这三张用户提供的参考，其颜色关系分析见 [颜色角色与对比](reference-color-relationships.md)。
