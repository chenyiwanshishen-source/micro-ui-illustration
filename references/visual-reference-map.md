# 参考图片与分析记录

本文件记录用户提供的参考图片分析。用户提供参考图时，AI 会把分析要点写在这里；没有参考图时，直接按默认规则和已有案例绘制，不要求用户提供图片。

---

## 一、 参考图分析要点

当用户提供参考图并说明想借鉴的地方时，AI 按以下五个方面分析，并将图片存入 `assets/reference-images/`：

1. **造型**：看真实控件怎么做切片（如标签缺口、文件夹背板、标尺刻度）。
2. **色彩**：看底板浅色、功能主色和深色焦点的面积分配。
3. **层次**：看物体间的前后遮挡关系、错层和留白。
4. **光影**：看阴影的扩散大小（stdDeviation）、偏移（dy）、透明度及是否有辅助弱纹理。
5. **区分借鉴与照搬**：
   - **可借鉴**：控件切片方式、尺度反差、空间层叠与微投影。
   - **不照搬**：原图的具体文字、特定品牌色、具体业务图标或整页排版。

> [!NOTE]
> 这里的“学习”是指把参考图里的视觉特点分析并记录下来，供画图时参考，不是训练大模型。
