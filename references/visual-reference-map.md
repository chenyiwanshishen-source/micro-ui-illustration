# 参考图谱与学习索引

本文件记录用户在实际绘制中提供的参考图片分析。绘制前若用户提供了新参考，AI 会在此提取特征与舍弃项；没有参考图时，AI 直接采用本项目的默认规范与已有原创案例，不强制要求上传。

---

## 一、 用户参考学习与索引流程

当用户提供参考图并指定借鉴方向时，AI 按以下维度进行分析，并将图片存入 `assets/reference-images/`：

1. **造型分析**：提取对象的真实控件切片特征（如：标签缺口、文件夹背板、真实刻度）。
2. **色彩与权重**：分析浅色承载、主功能实色、深色焦点的面积比例与明度节奏。
3. **空间与层次**：分析主体的前后遮挡、错层关系、相对尺度与留白分布。
4. **光影与材质**：分析阴影的扩散半径（stdDeviation）、偏移（dy）、透明度及是否有局部弱纹理。
5. **提取与舍弃**：
   - **推荐借鉴**：通用的视觉语法、尺度反差、空间层叠与交互暗示。
   - **严禁照搬**：原图特定的业务文案、营销标签、固定品牌色彩、特定图标或具体的整页布局。

> [!NOTE]
> 这里的“学习”是指 AI 对用户提供的视觉参考进行特征反编译与结构化记录，以指导当前画面的 SVG 代码构建，并非训练大模型底层权重。

## 三、 无参考图时的默认规则

当用户未提供任何参考图时：
- **直接使用内置设计规范**：详见 [`SKILL.md`](../SKILL.md) 与 [`references/micro-ui-construction.md`](micro-ui-construction.md)。
- **参考原创案例**：直接查阅已收录的开源原创案例 [`references/example-guide.md`](example-guide.md)（书签、日程、上传、移动内容），获取经过验证的 SVG 参数。
