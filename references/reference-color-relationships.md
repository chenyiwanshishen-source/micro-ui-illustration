# 颜色角色与对比原则

Micro-UI 插画通过颜色的深浅分工来区分主次，避免整张图颜色太平或太杂。

---

## 一、 颜色角色分工

| 颜色角色 | 功能说明 | 常见用法与处理 |
| :--- | :--- | :--- |
| **浅色承载层 (Surface / Canvas)** | 作为背景底板或浅色卡片，承托主体并后退 | 低饱和度、浅色（如 `#F8F9FA`、`#F0FDF4`），大面积铺开 |
| **功能主色层 (Accent / Primary)** | 标明控件身份与可读性 | 中等明度，用于开关、按钮、主要工具条与文件夹轮廓 |
| **深色焦点层 (Contrast / Focus)** | 形成焦点，引导第一眼视线 | 小面积点缀，用于关键指示、光标或前景主要图标 |
| **辅助弱线条 (Muted / Hatch)** | 可选，由 AI 根据画面需要决定是否添加 | 45° 斜向细线或微弱辅助线，颜色要淡，只在需要丰富背景或暗示空间时作为点缀 |

---

## 二、 配色原则

1. **按功能分工配色**：
   先分清哪些是底板、哪些是主功能、哪些是焦点，再定颜色和面积。角色可以按场景调换，不固定死板比例。
2. **同色系拉开深浅差**：
   同一个色系可以通过深浅色阶拉开层次（如 50、100、200、500、700），不用把所有色面都做成相近的浅色。相邻的同色实体可以通过留白、色阶差或轻柔微投影自然分开。
3. **优先使用变量**：
   接入具体项目时，优先映射到项目的颜色 Token，源码使用 `var(--illus-*)` 变量，不散写硬编码色值。
4. **画完自检**：
   - 颜色能不能分清谁主谁次？
   - 深色是不是集中在重点上，而不是碎碎地到处散落？
